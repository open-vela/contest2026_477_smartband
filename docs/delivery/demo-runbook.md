# 月薪喵现场演示与录制脚本

版本口径：candidate-04 为待实机验收候选；本脚本是操作与录制方案，不是成功记录。

## 演示前

确认固件标识、LLM 可用性及 Native UI 画面；只保留一个显示所有者。首选经主机指纹核验的 Wi-Fi SSH，ADB 为备用。设备 IP 由 DHCP 分配，不能固定套用历史地址。SSH 临时密钥放 `/tmp`，重启后需重新引导；不要录到网络密码、API 密钥或主机私钥。

先运行任务列表，确认没有上次遗留的一次性任务。记录设备时间。模拟观测始终在字幕和输入中标注 `[DEMO] 模拟观测，非传感器实测`。

## 主动闭环顺序

1. 先演示“20 秒后主动提醒”，通过当前固件受支持的 CLI/Agent 入口发送请求。
2. 记录返回的任务 ID、创建时间、到期时间和列表结果，证明创建时没有提前执行 Tool。
3. 保持连续录制，记录到期 Tool 执行、MoonCat 通道与实体屏幕提醒卡。cron 每 10 秒检查，约 20–30 秒窗口仅为设计预期，报告实际耗时。
4. 展示一次性任务已执行/移除。随后展示预览或列表，不紧接立即提醒。
5. 共做三轮。每轮尊重真实 cooldown，必要时在受控验收中重启 Agent 并明确记录；不得隐藏重启或把重置后的结果称为连续无重置运行。

立即提醒与定时提醒共享进程内 cooldown；久坐 45 分钟场景的 cooldown 也是 45 分钟。先立即弹卡再等 20 秒定时弹卡会污染演示。

## 异常验收

重复发送同一定时意图，核对任务列表是否只有一个对应任务。断网前记录网络状态和恢复方法；分别测试本地覆盖意图和需要云端的开放请求。记录实际返回，不把有限意图路由写成完整离线 LLM。只在当前候选固件存在路由器时测模型延迟和内存。
