# 电脑一键自动展示

连接 Gemini S1 的 USB，在 Windows 双击 `scripts/Start-MoonCatDemo.cmd`，展示窗口打开后自动开始。也可执行 `Start-MoonCatDemo.ps1 -Panel`，先打开控制面板，再点击“开始自动展示”。

## 展示内容

1. 首页和六种猫咪动画。
2. 天气卡片、城市选择、当前天气与预报。
3. 运动入口、开始运动、步数、卡路里、时长、心率、确认结束。
4. 健康入口、心率测量与历史、血压测量与历史。
5. 音乐播放器、播放列表、音量面板，以及消息页。
6. Rest 面板 → Try 20s → 到期提醒 → Take a break → 恢复倒计时 → Feeling better → 完成记录保存。
7. 返回首页，并恢复原来的猫咪动作。

每轮约 5 分钟，每页默认停留 4 秒，窗口可选 2 / 4 / 6 / 8 秒，也可勾选“循环展示”。点击“停止并返回首页”会收尾本轮启动的动作；已安排的 20 秒提醒可能需要等待其到期后取消，收尾期间请保持 USB 连接。关闭窗口也会先收尾。

演示期间请勿手动触摸板子或同时运行其他板端控制程序。程序使用现有固件的截图/虚拟触摸接口，逐步检查页面状态；无需重刷固件。运动、健康和提醒流程使用真实应用操作，会保存演示记录，健康与运动数值采用当前固件的数据来源。音乐仅展示控制页面，保留原音量与播放状态。

启动时将设备时钟同步到电脑本地时间，避免重启后首页显示 1970 年。

启动前若检测到已有运动或活跃提醒，会提示先处理；专注和免打扰设置保持原状。开启免打扰或暂停提醒时，本轮仅展示 Rest 面板。连接失败、页面状态不符或超时会停止自动推进并显示提示。

## 环境

- Windows，带 tkinter 的 Python 3.10+，ADB。
- 默认 ADB 端口 5038，使用 `ADB_LIBUSB=1`。只连接一块板子时自动识别序列号。
- 自动查找 PATH 中的 ADB 和工作区已有 Android 工具链；也可设置 `MOONCAT_ADB`。
- 启动器优先使用 `MOONCAT_PYTHON`，然后使用本机 Codex 的 Python 运行时或 PATH 中的 `pythonw.exe`。
- 需要 11 月决赛固件的 `MCAPP2` 应用状态与 Native UI 控制接口，坐标适配当前 320×240 布局。

```sh
python scripts/mooncat_demo.py --autostart
python scripts/mooncat_demo.py --adb /path/to/adb --serial 1234 --adb-port 5038
python scripts/mooncat_demo.py --headless --dwell 2 --log demo.jsonl
```

本机运行日志默认保存在 `%LOCALAPPDATA%/MoonCatDemo/`，仅包含展示步骤、时间和页面状态。`--capture DIR` 可选保存每一步截图，用于复核；该选项另需 Pillow。程序使用本机端口 47661 防止重复启动。
