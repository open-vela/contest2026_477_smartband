## 当前产品闭环

`安排提醒 → 保存任务 → 到期检查上下文 → 显示可操作卡片 → 开始 / 延后 / 暂停 → 恢复计时 → 用户确认完成 → 保存记录`

Rest 面板包括 Focus、Unwind、Rest 45m、Quiet、Resume 和 Try 20s。相对计时使用单调时钟，MCAPP2 持久化保留日历锚点并兼容旧记录；独立服务线程、通知 FIFO、后台健康和运动存储减少 UI 等待。

确定性快捷路径先处理明确请求；端侧 INT8 模型完成 now、preview、schedule、list、fallback 五类路由，复杂或低置信度请求由 Agent/云端处理。模型为 52,008 字节，624 条主机测试样本的 macro-F1 为 0.991879，独立 QuickApp 长提示集 30/30；参数由确定性代码校验。
